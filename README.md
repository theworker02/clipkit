# clipkit

Clip identifiers and kit tokens for idempotent workflows.

**Site:** https://theworker02.github.io/clipkit/

## Install / run

```bash
git clone https://github.com/theworker02/clipkit.git
cd clipkit
node src/cli.js
node --test
```
